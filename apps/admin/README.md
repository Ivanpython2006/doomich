# Думыч — панель администратора

Веб-панель для администраторов вузов и суперадминистратора установки: вузы и функции, кампусы и графы
навигации, группы, коды приглашения с листами QR для печати, импорт и источники расписания, база знаний
вуза, реестр моделей (активация версий, обученных `doomich-ml`), администраторы с 2FA и журнал действий.

Стек: Vite, React 19, TypeScript, Ant Design 6, TanStack Query, React Router. Работает с админ-API
сервера (`/admin/v1`, см. `services/api/src/doomich_api/api/admin.py`).

## Разработка

```bash
npm ci
DOOMICH_API=http://localhost:8000 npm run dev     # http://localhost:5173/admin/, /admin/v1 проксируется на API
```

Первый суперадминистратор создаётся на сервере:

```bash
doomich-api create-superadmin --login root
```

Команда печатает ссылку `otpauth://` — добавьте её в приложение-аутентификатор (Яндекс Ключ, Google
Authenticator, Aegis). Остальных администраторов создаёт суперадминистратор в разделе «Администраторы».

## Проверки и сборка

```bash
npm run typecheck   # tsc -b
npm run lint        # oxlint
npm test            # vitest: клиент API, проверка графа, листы QR, вход и права в панели
npm run build       # dist/ — статические файлы для Nginx
```

## Развёртывание

Панель — статика, собранная с `base: '/admin/'`. Nginx отдаёт `dist/` по пути `/admin/` и проксирует
`/admin/v1/` на API; оба пути открыты только из VPN или внутренней сети (см. `infra/nginx`).
Токен администратора хранится в `sessionStorage` и живёт до закрытия вкладки (на сервере — 8 часов),
отключение администратора действует сразу.

# Граф кампуса

Навигация («как пройти в 305») строит маршрут по графу кампуса: узлы — коридоры, аудитории, лестницы,
лифты, входы и заметные места; рёбра — переходы между ними. Граф загружается в панели администратора
(«Кампусы» → «Загрузить граф») и заменяет прежний целиком; текущий граф можно скачать, поправить и
загрузить обратно.

## Формат

```json
{
  "buildings": [
    {
      "slug": "a",
      "name": "Корпус А",
      "floors": [
        {
          "level": 1,
          "meters_per_px": 0.1,
          "nodes": [
            {"key": "a1-in", "kind": "entrance", "name": "Главный вход", "x": 0, "y": 0},
            {"key": "a1-c1", "kind": "corridor", "x": 100, "y": 0},
            {"key": "a1-st", "kind": "stairs", "x": 200, "y": 0}
          ]
        },
        {
          "level": 3,
          "meters_per_px": 0.1,
          "nodes": [
            {"key": "a3-st", "kind": "stairs", "x": 200, "y": 0},
            {"key": "a305", "kind": "room", "room": "305", "x": 300, "y": 50, "tags": ["компьютерный класс"]}
          ]
        }
      ]
    }
  ],
  "edges": [
    {"a": "a1-in", "b": "a1-c1"},
    {"a": "a1-c1", "b": "a1-st"},
    {"a": "a1-st", "b": "a3-st", "kind": "stairs", "length_m": 8, "accessible": false},
    {"a": "a3-st", "b": "a305"}
  ]
}
```

| Поле | Что значит |
|---|---|
| `key` | Уникальный во всём кампусе ключ узла. Те же ключи используются для фото в навигации по снимкам (`photos/<key>/`) — не меняйте их без нужды |
| `kind` | `corridor`, `room`, `stairs`, `elevator`, `entrance`, `poi` |
| `room` | Номер аудитории так, как он записан в расписании: по нему находится цель маршрута |
| `x`, `y` | Координаты на плане этажа в пикселях; `meters_per_px` переводит их в метры |
| `length_m` | Длина ребра; если не задана — считается по координатам (для лестниц и лифтов задайте явно) |
| `kind` ребра | `walk`, `stairs`, `elevator` — от этого зависят подсказки («поднимитесь на 3 этаж») |
| `accessible` | `false` — переход недоступен для маломобильных: маршрут «без лестниц» его обходит |

Рёбра двунаправленные. Панель проверяет файл до отправки: повторяющиеся ключи, рёбра на несуществующие
узлы, неизвестные типы.

## Как подготовить граф

1. Возьмите поэтажные планы (схемы эвакуации подойдут) и для каждого этажа задайте масштаб `meters_per_px`.
2. Расставьте узлы: у каждой двери аудитории, на перекрёстках коридоров, у лестниц и лифтов на каждом
   этаже, у входов. Чем чаще узлы в длинных коридорах, тем точнее подсказки.
3. Соедините соседние узлы рёбрами; лестницы и лифты между этажами — рёбрами с `kind` и `length_m`.
4. Загрузите граф и проверьте маршрут в приложении на паре известных путей.

Узлы, где снимаются фото для «Где я?», должны совпадать с узлами графа — см. [модели под кампусы](ml-training.md#навигация-по-фото-vprкампус).

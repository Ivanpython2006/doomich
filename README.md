# Думыч — ИИ-ассистент для студентов и преподавателей

«Думыч» — кроссплатформенное приложение для Android и ПК (Windows, Linux) с текстовым и голосовым ИИ-ассистентом.
Покупать отдельное устройство вроде умной колонки не нужно: ассистент живёт в телефоне и на компьютере.
Тяжёлые ИИ-модели работают на собственном сервере проекта или вуза, а не во внешних облаках,
поэтому приложение остаётся лёгким, а данные не уходят третьим лицам.

## Возможности

- Чат с ИИ текстом и голосом: точное распознавание речи и озвучка ответов.
- Актуальное расписание занятий, ответы на вопросы «что у меня завтра» и «где следующая пара».
- Ответы по загруженным документам (PDF, DOCX, XLSX) со ссылками на страницу — RAG.
- Конспекты лекций из аудиозаписи.
- Навигация по кампусу: «Где я?» по камере или описанию и маршрут до аудитории.
- Светлая и тёмная темы, русский и английский языки.
- Регистрация без персональных данных: псевдоним и пароль.

## Что в репозитории

| Часть | Каталог | Стек |
|---|---|---|
| Сервер: API, фоновые задачи, база | [`services/api`](services/api) | Python 3.13, FastAPI, PostgreSQL + pgvector, Celery, Alembic |
| Распознавание и синтез речи, навигация | [`services/asr`](services/asr), [`services/tts`](services/tts), [`services/nav`](services/nav) | GigaAM, Whisper, sherpa-onnx, ONNX Runtime |
| Приложение для Android | [`apps/client/mobile`](apps/client/mobile) | Flutter |
| Приложение для Windows и Linux | [`apps/client/desktop`](apps/client/desktop) | Flutter |
| Общее ядро и интерфейс клиентов | [`apps/client/packages`](apps/client/packages) | Dart, Riverpod |
| Панель администратора | [`apps/admin`](apps/admin) | React, TypeScript, Ant Design |
| ML-платформа: модели под вузы и кампусы | [`ml`](ml) | PyTorch, Transformers, PEFT |
| Развёртывание, мониторинг, CI | [`infra`](infra), [`.github/workflows`](.github/workflows) | Docker Compose, vLLM, nginx, Prometheus, Grafana, Ansible |

Готов первый релиз (R1): регистрация по приглашению без персональных данных, чат текстом и голосом с
озвучкой, расписание с универсальным импортом (Excel, CSV, iCalendar, сайты вузов), ответы по документам
со ссылками на источник, несколько вузов на одной установке с изоляцией данных. Для следующих релизов
заложен каркас: конспекты лекций, навигация по кампусу, слово активации, курсы.

## Быстрый старт

```bash
make dev-up          # стенд в Docker: API, воркеры, PostgreSQL, Valkey, nginx и панель — http://localhost:8080
make dev-superadmin  # первый администратор (вход в панель: /admin/)
```

Подробно — в [документации разработчика](docs/dev/README.md): локальная разработка, клиенты,
развёртывание на сервере с GPU, обучение моделей под вузы и кампусы.
